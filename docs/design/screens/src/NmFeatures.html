What depends on what

Payslips in self-service need Payroll, or pay documents from an external payroll. Unpaid leave in pay needs Leave. Joiners' KETs need Letters. Turning off a feature another one needs is refused with the reason, and turning one off first lists what is still outstanding.

Using another system

Choose "Another system" for payroll or leave if Cognizhi keeps an existing provider. Nemura's feature then doesn't load, and Fyniq takes the payroll journal from that system instead.
