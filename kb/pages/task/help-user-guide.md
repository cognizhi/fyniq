# Read the user guide in Fyniq: open a page, search it, print it

## What the guide is

- The user guide is in Fyniq: how to do each thing, and what its words mean.
- It shows the pages for the person's roles; in Basic mode the Basic pages, with how many more Expert mode adds.
- It is built into each release, so it describes the Fyniq in use; the assistant reads the same pages to answer how-to questions ([[ai.assistant]]).

(src: docs/user-guide/help.md#what-it-is)

## Open a page

- **Help** in the header, then **User guide**, then a page.
- A page lists its sections as headings; a link to another page of the guide opens it.
- A page's address names it, so it can be sent to someone; a section's address opens at that section.

(src: docs/user-guide/help.md#open-a-page)

## Search the guide

- **Search the guide** keeps the pages whose title or words hold every word typed.
- With none, try fewer words, or ask the assistant.

(src: docs/user-guide/help.md#search-the-guide)

## Print a page

- **Print** on a page prints it without the header, the navigation and the buttons.

(src: docs/user-guide/help.md#print-a-page)

## Take the tour

- At the first sign-in Fyniq offers a short tour of the pages the person will use, up to 7 steps and about 2 minutes: **Start the tour** or **Not now**.
- Each step points at a part of the page and says what it is for; **Next** and **Back** (or → and ←) move, **Skip tour** or Esc ends it; it clicks and changes nothing.
- Left part-way, it is offered again to **Resume the tour**; **Help** › **Take the tour again**, or the command palette, replays it; each role sees its own steps.

(src: docs/user-guide/help.md#take-the-tour)
