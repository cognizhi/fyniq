# Proposal

## Why

`p0-api-conventions-authz` built the conventions as middleware and tested them on P0's first
endpoints, but the requirements themselves are P1 (§8.18, §8.18.1). Every later change adds its
operations to the contract first (golden rule 4). The conventions every one of them relies on are
therefore claimed here, before wave 2, along with the parts P0 did not build.

## What Changes

- **The API-first rule (FR-INT-01):**
  - the web app calls only the public API through the generated client;
  - an archtest already checks this, and is extended to every new screen;
  - the API applies the same domain commands and approval policies as the UI.
- **The client-class model from P1, for MCP (FR-INT-02, P1 part):**
  - `integration` clients and personal access tokens, issued by the OAuth server (ADR-T3), with rate
    limits and audit per client;
  - opening third-party access is P2.
- **Versioning, errors, idempotency, concurrency and lists, claimed with tests on the P1 operations
  (FR-INT-06…10):**
  - deprecation notices with the `Deprecation` and `Sunset` headers;
  - every invalid field reported at once in one problem response.
- **Long and bulk operations (FR-INT-11):** `202 Accepted` with an operation resource, and a result
  per item.
- **Machine-readable contracts (FR-INT-13):** JSON Schema for every resource, a published API
  reference, `llms.txt` and an agent guide.
- **Preview before commit (FR-INT-14):** `Prefer: return=preview` returns the validation result and
  the ledger impact, and commits nothing.
- **Rate limits and quotas (FR-INT-16):** `RateLimit` and `RateLimit-Policy` headers, and
  `Retry-After` on 429.
- **The TypeScript client (FR-INT-17, P1 part):** already generated by `make openapi`; packaged as the
  SDK. The Go and Python clients are P2.
- **Event schema versions (§12.10):** `contracts/events/` becomes the source of truth for every event
  type, `fyniq.<object>.<event>.v<N>`.

## Capabilities

### New Capabilities

None.

### Modified Capabilities

None (`skip_specs: true`). This change builds:
- `integrations/public-api`: FR-INT-01, 02 (P1 part), 06…11, 13, 14, 16 and 17 (P1 part);
- the event-schema requirement of `platform/release-and-versioning`.

## Impact

- **Code and contracts:**
  - `internal/api` middleware;
  - `contracts/openapi/fyniq.v1.yaml`;
  - a new `contracts/events/`;
  - `apps/web/src/api`;
  - the archtest for private endpoints.
- **The OAuth server's client registration (ADR-T3):** the client classes, shared with
  `p1-users-roles` (SEC-07).
- **Screens:** none.
- **Breaking:** nothing. Every change inside `/v1` is additive, and `oasdiff` must stay clean
  (QA-API-02).
