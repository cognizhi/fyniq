Set up the emails in DBS IDEAL

Guide
  1. 2In DBS IDEAL, schedule the daily account report for the USD wallet in MT940 format and send it to that address.
  2. 3Turn on incoming-funds alerts for the same account, to the same address. Alerts speed up matching; only the daily report adds bank lines.
  3. 4At month end, the DBS e-statement confirms the closing balance.

Fyniq accepts only emails that pass SPF, DKIM and DMARC checks for DBS. Anything else waits in quarantine until you accept it. Attachments are scanned for malware.

Read-only, by design

Fyniq only reads balances and transactions. It never asks for your bank password and never uses screen-scraping services.

Payments still leave the way they do today: as an approved payment file that someone uploads to DBS.
