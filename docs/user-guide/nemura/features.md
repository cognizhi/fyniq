# Switch Nemura's features on or off

## What it is

Each optional feature of Nemura is **On**, **Off**, or held by **Another system**. People records is always on. A feature that is off
has no pages and no jobs. Switching one off keeps its records; they stay readable by the people who may read them.

## Before you start

- You need to be the HR administrator or the Owner.
- Know which other features depend on it: Payroll needs Leave, and Onboarding needs Letters.

## Steps

1. Open **Features**.
2. Choose the state for a feature. For **Another system**, type the name of the system that holds its data.
3. Select **Apply**. Nemura answers in words if it cannot.

## Common problems

- **Payroll needs Leave to be on or held by another system.** Switch Leave on first, or give Leave to another system.
- **Another feature needs this.** Switch the feature the message names off first.
- **Work is still open in this feature.** Record how each open thing will be handled, then switch the feature off.
- **That feature cannot be switched on yet.** Hiring, Performance, Onboarding and Time arrive in later releases, and Payroll needs the Owner and a second approver, which arrives with Payroll.
