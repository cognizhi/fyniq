# Grants and principals the P2 build added, for a human reviewer

Every row is `needs-human-review` (AGENTS.md "Safety"): a person who did not write it reads the migration and the test named. Before production this review is
waived by the founders' decision of 14 Oct 2026; it returns before the first production deploy. Nothing here widens the AI or MCP surface: no tool, scope or
grant of the AI was added, and a test holds the payment-link capability to the API.
