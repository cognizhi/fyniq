# Read the user guide

## What it is

The user guide is in Fyniq: how to do each thing, and what its words mean. It shows the pages for your roles; in
Basic mode it shows the Basic pages and says how many more Expert mode adds. It is built into each release, so it
describes the Fyniq you are using, and the assistant reads the same pages to answer how-to questions.

## Open a page

- Select **Help** in the header, then **User guide**, and select a page.
- A page lists its sections as headings; a link to another page of the guide opens that page.
- A page's address names it, so you can send it to someone, and a section's address opens at that section.

## Search the guide

- Type in **Search the guide**: the pages whose title or words hold every word you typed stay listed.
- If no page holds them, try fewer words, or ask the assistant.

## Print a page

- On a page, select **Print**. The header, the navigation and the buttons are left out of the print.
